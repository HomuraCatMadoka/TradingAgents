## Project Overview

This project transforms the original TradingAgents framework (multi-agent LLM trading system) into a DeFi-focused analysis agent. The transformation includes:

- Multi-chain DeFi data integration (Ethereum, Arbitrum, Optimism, Base, Polygon)
- Protocol analysis tools (TVL, APY, yield opportunities)
- On-chain data access via Web3.py
- Market data from CoinGecko, DeFi Llama, The Graph
- LangChain-compatible tool interfaces
