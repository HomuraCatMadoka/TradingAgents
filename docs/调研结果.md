### **Part 1: DEX（去中心化交易所）协议**

#### **协议名称: Uniswap V3**

**1. 基本信息**
*   **协议类型**: AMM (集中流动性)
*   **支持的区块链**: Ethereum, Arbitrum, Optimism, Polygon, Base, BNB Chain
*   **官网**: `https://uniswap.org`
*   **文档**: `https://docs.uniswap.org`

**2. DeFi Llama 集成**
*   **协议 Slug**: `uniswap-v3`
*   **TVL 获取方式**: `https://api.llama.fi/protocol/uniswap-v3` (支持多链细分)
*   **历史数据**: 支持获取完整的历史 TVL 和 Volume。

**3. The Graph 子图**
*   **子图名称**: `uniswap/uniswap-v3` (Ethereum)
*   **子图端点**:
    *   Ethereum: `https://api.thegraph.com/subgraphs/name/uniswap/uniswap-v3`
    *   Arbitrum: `https://api.thegraph.com/subgraphs/name/uniswap/uniswap-v3-arbitrum`
*   **关键查询示例**:
```graphql
# 获取 Top 10 流动性池
{
  pools(first: 10, orderBy: totalValueLockedUSD, orderDirection: desc) {
    id
    token0 { symbol }
    token1 { symbol }
    totalValueLockedUSD
    volumeUSD
    feeTier
  }
}

# 获取池的 24h 数据
{
  poolDayDatas(
    first: 1
    orderBy: date
    orderDirection: desc
    where: { pool: "0x88e6a0c2ddd26feeb64f039a2c41296fcb3f5640" } # USDC/ETH 0.05%
  ) {
    date
    volumeUSD
    feesUSD
    tvlUSD
  }
}
```

**4. 关键指标与计算方法**
*   **流动性深度 (TVL)**: `Σ (Reserve_i * Price_i)`。数据直接来自子图 `totalValueLockedUSD`。
*   **费用收入**:
    *   费率结构: 0.01%, 0.05%, 0.30%, 1.00%。
    *   LP 收益: `Volume * FeeTier`。
*   **APY 计算**:
    *   公式: `(24h Fees * 365) / TVL`。
    *   注意: 此 APY 为池平均值，个人 LP 的实际 APY 取决于其设置的价格区间（Range）。
*   **无常损失 (IL)**: V3 的集中流动性会放大 IL，需使用专门工具（如 Revert Finance）计算。

**5. 智能合约地址 (Ethereum)**
*   **Factory**: `0x1F98431c8aD98523631AE4a59f267346ea31F984`
*   **Router**: `0xE592427A0AEce92De3Edee1F18E0157C05861564`
*   **NFT Manager**: `0xC36442b4a4522E871399CD717aBDD847Ab11FE88`

**6. 风险评估**
*   **审计报告**: Trail of Bits, ABDK。
*   **TVL 等级**: > $1B (蓝筹)。
*   **风险**: 智能合约风险极低，主要为市场风险（IL）。

#### **协议名称: Curve Finance**

**1. 基本信息**

**2. DeFi Llama 集成**
*   **协议 Slug**: `curve-dex`
*   **TVL 获取方式**: `https://api.llama.fi/protocol/curve-dex`

**3. The Graph 子图**
*   **子图名称**: 社区维护版本较多，建议交叉验证。
*   **子图端点**:
    *   Ethereum (社区): `https://api.thegraph.com/subgraphs/name/aurtbs/curve-finance`
*   **注意**: Curve 的子图生态较乱，推荐优先使用官方 API。

**4. 官方 API (推荐)**
*   **API 端点**: `https://api.curve.fi/api/getPools/ethereum/main`
*   **数据类型**: 直接返回池列表、TVL、交易量、**Base APY** 和 **CRV Rewards APY**。
*   **认证**: 无需 API Key。

**5. 关键指标与计算方法**
*   **APY 计算**:
    *   公式: `Total APY = Base APY + (CRV APY * Boost)`
    *   Boost: 取决于用户锁定的 veCRV 数量，最高 2.5 倍。
*   **费用结构**: 通常为 0.04%，其中 50% 给 LP，50% 给 veCRV 持有者。

**6. 智能合约地址 (Ethereum)**
*   **Address Provider**: `0x0000000022D53366457F9d5E68Ec105046FC4383` (核心入口)
*   **3pool**: `0xbEbc44782c7db0a1a60Cb6fe97d0b483032FF1C7`

**7. 风险评估**
*   **历史漏洞**: 2023年7月 Vyper 编译器重入漏洞导致部分池被盗。
*   **风险等级**: 蓝筹，但需警惕外部依赖风险。

### **Part 2: 借贷协议**

#### **协议名称: Aave V3**

**1. 基本信息**
*   **协议类型**: 超额抵押借贷
*   **支持的区块链**: Eth, Arb, Op, Poly, Avax, Base
*   **官网**: `https://aave.com`

**2. DeFi Llama 集成**
*   **协议 Slug**: `aave-v3`
*   **TVL 分类**: API 区分 `totalLiquidityUSD` (存款) 和 `totalDebtUSD` (借款)。

**3. The Graph 子图**
*   **子图端点**:
    *   Ethereum: `https://api.thegraph.com/subgraphs/name/aave/protocol-v3`
*   **关键查询**:
```graphql
{
  reserves(where: {usageAsCollateralEnabled: true}) {
    symbol
    liquidityRate      # 存款利率 (Ray单位)
    variableBorrowRate # 借款利率 (Ray单位)
    utilizationRate
    totalDeposits
    totalCurrentVariableDebt
  }
}
```

**4. 关键指标与计算方法**
*   **利率格式**: 返回数据为 **Ray** (10^27)，实际利率需除以 10^27。
*   **资金利用率**: `TotalDebt / TotalDeposits`。
*   **健康因子 (HF)**: `(Collateral * Threshold) / Debt`。HF < 1.0 触发清算。

**5. 智能合约地址**
*   **Pool**: `0x87870Bca3F3fD6335C3F4ce8392D69350B4fA4E2` (Eth Mainnet)

**6. 风险评估**
*   **TVL 等级**: > $10B (蓝筹)。
*   **风险**: 极低，拥有完善的 Risk DAO 和安全模块。

#### **协议名称: Pendle Finance**

**1. 基本信息**
*   **协议类型**: 收益代币化 (Yield Tokenization)
*   **支持的区块链**: Eth, Arb, BNB
*   **官网**: `https://pendle.finance`

**2. 数据源**
*   **The Graph**: 官方 GitHub 维护了详细列表。
    *   Arbitrum: `https://api.thegraph.com/subgraphs/id/ExXGU3ub2nrT5stPk5cH4hSk2qunJcMcP8eX5GAhrZhe`

**3. 核心机制 (PT/YT)**
*   **PT (本金代币)**: 零息债券逻辑，折价购买，到期回归 $1。用于锁定**固定收益**。
*   **YT (收益代币)**: 获得到期前的所有收益流。用于**做多收益率**。
*   **隐含 APY**: 市场根据 PT/YT 价格博弈出的预期收益率。

**4. 风险评估**
*   **风险**: 产品逻辑复杂，YT 具有时间衰减特性 (到期归零)，若收益率不及预期将面临本金全损。

### **1. Beefy Finance**

*   **基本信息**:
    *   **协议名称**: Beefy Finance
    *   **协议类型**: 多链收益优化器 (Multi-Chain Yield Optimizer)
    *   **支持的区块链**: 支持 >20 条链 (Arbitrum, Optimism, Polygon, Base, BNB Chain 等)
    *   **官网**: `https://beefy.com`

*   **数据源配置**:
    *   **官方 API (强烈推荐)**: Beefy 的数据非常开放，API 极其完善。
        *   **端点**: `https://api.beefy.finance`
        *   **TVL**: `GET /tvl` (返回所有 Vault 的 TVL)
        *   **APY**: `GET /apy` (返回所有 Vault 的实时 APY)
        *   **LPs**: `GET /lps` (返回底层 LP 的详细信息)
    *   **DeFi Llama**: Slug `beefy`。

*   **核心机制**:
    *   **mooTokens**: 用户存入 LP Token，获得 `mooToken`。
    *   **自动复利**: 协议自动收割奖励并卖出，复投到底层 LP 中。mooToken 数量不变，但其兑换底层 LP 的比例会随时间增长。

*   **风险评估**:
    *   **风险等级**: 成熟。
    *   **特定风险**: Beefy 是建立在其他 DEX/Lending 协议之上的，存在**嵌套风险**。如果底层 Farm（例如某条新链上的小 DEX）跑路，Beefy Vault 也会归零。

        totalRethSupply
      }

*   **风险评估**:
    *   **风险等级**: 蓝筹。
    *   **优势**: 相比 Lido 更去中心化，抗审查性更强。

    *   **DSR (Dai Savings Rate)**: sDAI 的存款利率，是 DeFi 的基准利率之一。

*   **风险评估**:
    *   **风险等级**: 蓝筹 (DeFi 基石)。
    *   **风险点**: 对 RWA (现实世界资产) 和 USDC 的中心化依赖。

### **2. GMX**

*   **基本信息**:
    *   **协议名称**: GMX
    *   **协议类型**: 去中心化永续合约 (Perp DEX)
    *   **支持的区块链**: Arbitrum, Avalanche
    *   **官网**: `https://gmx.io`

*   **数据源配置**:
    *   **官方 API**: `https://api.gmx.io`
        *   `/v1/stats`: 获取总体统计。
        *   `/v2/markets`: 获取 V2 市场数据。
    *   **The Graph**: `gmx-io/gmx-stats`。

*   **核心机制**:
    *   **GLP (V1)**: 一篮子资产指数 (ETH, BTC, USDC 等)，作为交易者的对手盘。交易者亏损则 GLP 盈利。
    *   **GM (V2)**: 隔离池模式，风险更可控。

*   **关键指标**:
    *   **AUM**: GLP 池的总资产价值。
    *   **Open Interest (OI)**: 多空持仓总量。

*   **风险评估**:
    *   **风险等级**: 蓝筹。
    *   **风险点**: 在单边极端行情下，GLP 持有者可能面临亏损（作为交易员的对手盘）。

    *   **风险点**: 机制极其复杂，涉及多个子协议的嵌套。
